# Τοπικό JSON API & Ρόλοι

Όλα τα δεδομένα (μέλη, πληρωμές, οφειλές, πακέτα, κρατήσεις, ανακοινώσεις, είσοδοι, χρήστες προσωπικού)
βρίσκονται στο `db/db.json` και σερβίρονται από [json-server](https://github.com/typicode/json-server/tree/v0)
στη θύρα **3001**. Δεν χρησιμοποιείται Supabase ούτε Vercel.

## Εκκίνηση

```bash
npm install
npm run api       # JSON API στο http://localhost:3001
npm run dev       # σε δεύτερο terminal
# ή και τα δύο μαζί:
npm run dev:api
```

- Την πρώτη φορά το `db/seed.json` παράγεται αυτόματα και αντιγράφεται στο `db/db.json`.
- `npm run api:reset` → επαναφορά στα αρχικά δεδομένα (σβήνει ό,τι έχει αλλάξει).
- `npm run seed` → ξαναφτιάχνει το `db/seed.json` με ημερομηνίες γύρω από τη σημερινή
  ([generate-seed.mjs](../scripts/generate-seed.mjs)): ~500 μέλη, owner + 7 coaches + developer, 8 πακέτα,
  ~1.500 πληρωμές (6 μήνες), οφειλές, λήξεις, ανακοινώσεις, το εβδομαδιαίο πρόγραμμα ομαδικών και personal
  training (±2 εβδομάδες) και ~300 εισόδους/ημέρα για 30 ημέρες (αιχμή 17:00–21:00, μέσα στο ωράριο).
  Μετά τρέξτε `npm run api:reset`.
- Τα `db/db.json` και `db/seed.json` δεν μπαίνουν στο git (παράγονται).
- Το Vite προωθεί το `/data/*` στο `http://localhost:3001` (βλ. `vite.config.ts`).
- Οι φωτογραφίες μελών αποθηκεύονται ως data URL στο πεδίο `photo_url`.

## Ρόλοι

| Ρόλος | Ποιος | Πρόσβαση |
|-------|-------|----------|
| `admin` | Developers | Όλα |
| `owner` | Αφεντικό εταιρείας | Όλα εκτός από τις ρυθμίσεις developer (SMS/Email providers, ρυθμός αποστολής) |
| `trainer` | Γυμναστές | Όλα εκτός από οικονομικά (πληρωμές, οφειλές, έσοδα, τιμές/διαχείριση πακέτων), ρυθμίσεις και χρήστες |
| μέλος | Πελάτες | Μόνο το member portal (`/member`), login με το τηλέφωνο του μέλους |

Τα δικαιώματα ορίζονται στο [permissions.ts](../src/features/auth/permissions.ts).

## Dashboard ανά ρόλο

- **Owner** — `/dashboard`: παρακολούθηση γυμναστηρίου με **dropdown γυμναστή** (όλοι ή ένας-ένας,
  κρατιέται στο URL `?trainer=`): πρόγραμμα 7 ημερών, πίνακας γυμναστών (μαθήματα, κρατήσεις, πληρότητα,
  επόμενο μάθημα), είσοδοι live, ώρες αιχμής, πληρότητα μαθημάτων, μέλη για follow-up.
  `/finance` (**Οικονομικά**): έσοδα μήνα/μήνα, ανά πακέτο & τρόπο πληρωμής, οφειλές, ανανεώσεις, μέλη.
- **Trainer** — το ίδιο dashboard γυμναστηρίου με τα δικά του μαθήματα τονισμένα, χωρίς οικονομικά
  και χωρίς επιλογή γυμναστή.
- **Admin** — tabs **Σύστημα** (API, εγγραφές, ποιότητα δεδομένων, ρόλοι & συνδέσεις, δραστηριότητα)
  και **Γυμναστήριο** (όπως του owner). Έχει και τη σελίδα Οικονομικά.

## Διαχείριση χρηστών

Μενού **Χρήστες** (`/staff`), για admin και owner: δημιουργία με αρχικό κωδικό, επεξεργασία ονόματος/ρόλου,
νέος κωδικός, διαγραφή. Ο owner διαχειρίζεται μόνο owners και trainers· κανείς δεν αλλάζει τον δικό του ρόλο
ή διαγράφει τον εαυτό του. Κάθε χρήστης αλλάζει τον κωδικό του από το εικονίδιο κλειδιού πάνω δεξιά.

## Περιορισμοί

Μόνο για τοπική χρήση: το json-server δεν έχει authentication, οι κωδικοί είναι σε απλό κείμενο στο `db.json`
και οι κανόνες των ρόλων ελέγχονται μόνο στην εφαρμογή. Όποιος έχει πρόσβαση στη θύρα 3001 βλέπει/αλλάζει τα πάντα.
